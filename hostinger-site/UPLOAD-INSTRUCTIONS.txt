Nazam LLC Hostinger Upload Instructions

1. Log in to Hostinger hPanel.
2. Open File Manager for nazamllc.com.
3. Open the public_html folder.
4. Upload the contents of this hostinger-site folder into public_html:
   - index.html
   - styles.css
   - script.js
   - robots.txt
   - sitemap.xml
   - llms.txt
   - images/ (entire folder)
5. Make sure index.html is directly inside public_html, not nested inside another folder.
6. Visit https://nazamllc.com/ after upload and test:
   - Header navigation links (Services, Work, Method, FAQ, About, Contact)
   - Hero CTAs ("See What We Do", "Book a Free Strategy Call")
   - Labs filter pills (Automation / Marketplace / App Dev)
   - FAQ accordion open/close
   - mailto: links (admin@nazamllc.com) open the visitor's email client
   - LinkedIn link (https://linkedin.com/in/muhammad-nazam)
   - Scroll-reveal animations and sticky nav hide/show on scroll
   - Mobile layout

Notes:
- This is a static website. It does not require Node, React, Vite, or a database.
- There is no contact form on this site — all contact CTAs are mailto: links to admin@nazamllc.com.
- index.html links to styles.css and script.js with a "?v=" version query string. Bump that version
  (e.g. ?v=3 -> ?v=4) in index.html whenever you update styles.css or script.js, so Hostinger/LiteSpeed
  cache and visitors' browsers pick up the new files instead of serving a stale cached copy.
- Do not test the page by double-clicking index.html for anything beyond a quick visual check;
  serve it from a local web server or the live domain for full parity.
- Important domain check: this upload is configured for https://nazamllc.com/ without a hyphen. If you
  later switch to a hyphenated domain, add/fix its DNS records in Hostinger and update the canonical URL,
  Open Graph URLs, and JSON-LD in index.html, plus robots.txt, sitemap.xml, and llms.txt.
- If the design still looks broken after upload, clear the Hostinger/LiteSpeed cache and test in a
  private browser window.
